# 03 · HTML: formulários e atributos

## Componentes de formulário
| Tipo | Código |
|---|---|
| Caixa de texto | `<input type="text" />` |
| Senha | `<input type="password" />` |
| Checkbox | `<input type="checkbox" />` |
| Opção (radio) | `<input type="radio" />` |
| Lista de seleção | `<select><option>Escolha</option></select>` |
| Texto com várias linhas | `<textarea></textarea>` |
| Botão | `<button>Gravar</button>` |

## Atributo
Característica de uma tag, escrita dentro da tag de abertura: `nome="valor"`.

| Atributo | Efeito |
|---|---|
| `size="10"` | largura da caixa de texto |
| `maxlength="5"` | máximo de caracteres |
| `placeholder="..."` | dica exibida enquanto vazio |
| `rows` / `cols` | linhas/colunas do `textarea` |
| `id` / `name` | identificador do campo |
| `value` | valor inicial |

## Outras
`<br>` pula linha.

## Por que `id` importa
É por ele que o CSS e o JavaScript encontram o elemento (ver notas 05 e 09).

## Exercício feito
Montar uma página só com HTML reproduzindo um formulário-modelo.
