# 14 · Glossário

| Termo | Significado |
|---|---|
| Atributo | característica de uma tag HTML (`id`, `size`, `value`) |
| Ajax | requisição assíncrona ao servidor sem recarregar a página |
| Cliente | navegador do usuário |
| Servidor | máquina que responde às requisições |
| CSS | linguagem de estilo das páginas |
| DOM | representação em árvore da página, manipulável por JS |
| Feedback | resposta visual/sonora às ações do jogador |
| Gameplay | experiência de jogar |
| GDD | *Game Design Document* |
| HTML | linguagem de marcação das páginas |
| `id` | identificador único de um elemento |
| jQuery | biblioteca JS que simplifica o acesso ao DOM |
| Mecânica | regra de interação do jogo |
| Padding | espaço interno de uma caixa CSS |
| PBL | aprendizagem baseada em problemas |
| Requisito | necessidade que o software deve atender |
| Seletor | parte do CSS que escolhe elementos |
| Soft skills | habilidades comportamentais |
| Tag | marca de início/fim em HTML |
| Console | painel do navegador com mensagens e erros de JS |
